# Wechaty Official Examples Directory

The `examples/` directory provides starter bots for learning Wechaty 2 with Node.js 26 and TypeScript 7. If you are new to Wechaty, start with [ding-dong-bot.ts](ding-dong-bot.ts).

## Starter & Basic Examples

| Filename | Description |
| --- | --- |
| [ding-dong-bot.ts](ding-dong-bot.ts) | Recommended starter template using `PuppetNeo` |
| [basic/ding-dong-bot.ts](basic/ding-dong-bot.ts) | Basic ding-dong bot with `PuppetNeo` |
| [basic/the-worlds-shortest-chatbot-code-in-6-lines.ts](basic/the-worlds-shortest-chatbot-code-in-6-lines.ts) | Minimal 6-line Wechaty chatbot example |
